# AGENT.md — для ИИ-агента, который разворачивает и запускает проект

Этот файл — для ИИ-агента (Claude Code, Codex, Hermes и т. п.), которому поручили установить, настроить, запустить или проверить «Ассистента исследователя» на новой машине. Правила разработки — изменение кода, тесты, стиль — в [AGENTS.md](AGENTS.md). Описание для человека — в [README.md](README.md).

## Что это

Агент отвечает на вопросы по библиотеке научных статей утверждениями с дословными цитатами: статья, раздел, страница. Библиотека уже собрана и лежит в `data/library.sqlite`: 72 статьи, темы «speculative decoding» (en) и «машинное обучение в медицине» (ru). Индекс поиска по смыслу — `data/vectors/text-embedding-bge-m3.npz`.

Чат-модель — любой сторонний AI-сервис с OpenAI-совместимым API и вызовом инструментов (tools). Выбирается одной строкой в `.env`. Эмбеддинги bge-m3 считает LM Studio. Без него поиск работает по словам (BM25), тоже рабочий вариант.

## Первый запуск — порядок действий

Выполняй по шагам. После каждого шага проверь результат, прежде чем идти дальше.

1. **Python и uv.** Нужен Python 3.12+ и `uv` (`pip install uv` или https://docs.astral.sh/uv/). Команды выполняй из корня проекта (где `pyproject.toml`).
   ```bash
   uv sync
   ```
2. **`.env`.** Скопируй образец и спроси у пользователя, какой провайдер он хочет. Ключ пользователь вписывает сам или даёт явно в чате. Не придумывай ключи и не ищи их в чужих конфигурациях без прямой просьбы.
   ```bash
   cp .env.example .env
   ```
   В `.env` задай `LLM_PROVIDER=<имя>` и ключ этого провайдера. Профили:

   | `LLM_PROVIDER` | сервис | ключ | модель по умолчанию |
   |---|---|---|---|
   | `lmstudio` | LM Studio, локально | не нужен | `qwen3.5-4b` |
   | `ollama` | Ollama, локально | не нужен | задать `LLM_OLLAMA_MODEL` |
   | `inception` | Mercury 3 | `INCEPTION_API_KEY` | `mercury-3` |
   | `openai` | OpenAI | `OPENAI_API_KEY` | задать `LLM_OPENAI_MODEL` |
   | `anthropic` | Claude (OpenAI-совместимый эндпоинт) | `ANTHROPIC_API_KEY` | `claude-sonnet-5-5` |
   | `openrouter` | OpenRouter | `OPENROUTER_API_KEY` | задать `LLM_OPENROUTER_MODEL` |
   | `deepseek` | DeepSeek | `DEEPSEEK_API_KEY` | `deepseek-chat` |
   | `gemini` | Gemini API | `GEMINI_API_KEY` | задать `LLM_GEMINI_MODEL` |
   | `custom` | любой OpenAI-совместимый | `LLM_CUSTOM_API_KEY` | `LLM_CUSTOM_BASE_URL` и `LLM_CUSTOM_MODEL` |

3. **Проверка провайдера.**
   ```bash
   uv run research-assistant providers
   uv run research-assistant check
   ```
   `check` должен напечатать «Вызов инструмента: да» и «Счётчики usage: да». Если модель не вызывает инструменты, агент с ней работать не сможет: выбери другую.
4. **Эмбеддинги (желательно).** Нужен LM Studio с моделью bge-m3:
   ```bash
   lms get https://huggingface.co/ggml-org/bge-m3-Q8_0-GGUF
   lms load text-embedding-bge-m3 -y
   lms server start
   ```
   Без эмбеддингов в ответах инструментов появляется пометка «Semantic search is unavailable», и поиск идёт по словам. Для облачного провайдера LM Studio нужен только для эмбеддингов. Для `lmstudio` чат-модель грузится с контекстом 16K:
   ```bash
   lms load qwen3.5-4b --context-length 16384 --gpu max -y
   ```
5. **Проверка библиотеки и поиска** (модель не нужна):
   ```bash
   uv run research-assistant library
   uv run research-assistant search "почему падает ускорение при слабой черновой модели"
   ```
6. **Вопрос агенту и веб-интерфейс:**
   ```bash
   uv run research-assistant ask "Почему ускорение спекулятивного декодирования падает при слабой черновой модели?"
   uv run research-assistant ui
   ```
   Ответ — утверждения с цитатами вида `«…» — Название (год), раздел «…», с. N [s123]`. Интерфейс открывается на http://localhost:8501.
7. **Тесты** (офлайн, без сети и модели):
   ```bash
   uv run pytest -q
   ```

## Команды

| задача | команда |
|---|---|
| профили и проверка модели | `providers`, `check`, разово `--provider <имя> <команда>` |
| вопрос / диалог / веб | `ask "<вопрос>"`, `chat`, `ui` |
| библиотека и поиск | `library`, `show <id>`, `search "<запрос>"`, `entities` |
| пополнение библиотеки (меняет данные!) | `ingest "<тема>"`, `parse`, `index`, `annotate` |
| оценка | `eval-agent --variant prefetch`, `eval-retrieval`, `eval-entities` |
| библиотека для другого агента (MCP) | `mcp` (только чтение), `mcp --allow-model`, `mcp --allow-write` — см. docs/mcp.md |

Все команды запускаются как `uv run research-assistant <команда>`. Справка: `--help`.

## Правила для агента

- **Секреты.** Не печатай, не коммить и не копируй значения ключей из `.env`. О ключе говори только «задан / не задан» (это показывает `providers`). `.env` не коммитится.
- **Данные.** `data/library.sqlite` и `data/vectors/` не правь вручную. Команды `ingest`, `parse --force`, `index`, `annotate` и добавление статей из чата меняют библиотеку и тратят ключ провайдера — запускай их только по просьбе пользователя. Агент добавляет статьи из интернета, только если пользователь прямо попросил («добавь», «скачай»).
- **Промпт и инструменты.** `SYSTEM_PROMPT` (`agent/prompts.py`) и схемы в `agent/tools.py` не меняй без задачи. Они откалиброваны экспериментами (docs/experiments.md, E5) и связаны с датасетом дообучения через `prompt_hash`.
- **Модели в LM Studio.** Не выгружай и не перезагружай модели, которые может использовать другая программа или сессия. Перед тяжёлыми прогонами (`eval-agent` на локальной модели) спроси пользователя и проверь загрузку GPU (`nvidia-smi`).
- **Деньги.** Облачные провайдеры платные. Перед `eval-agent` или массовыми запросами назови примерный объём (≈5–25 тыс. токенов на вопрос) и получи согласие.
- **Публикация.** Тексты статей и производные данные — только для личного учебного использования. Не выкладывай их и не отправляй никуда, кроме выбранного провайдера модели.
- **Дообучение отложено.** Код дообучения (`finetune/`, `scripts/train_sft.py`, `scripts/make_train_bundle.py`, docs/finetune.md) в проекте есть, но запускать его без отдельной просьбы не нужно.

## Если что-то не работает

| симптом | что делать |
|---|---|
| `Не задана переменная …` | заполни названную переменную в `.env` (`providers` показывает, чего не хватает) |
| `Connection error` в `check` | локальный сервер не запущен (`lms server start` / `ollama serve`) или нет сети |
| 401 / 403 | неверный ключ или нет доступа к модели |
| 404 / «модель не найдена» | неверный id модели (`LLM_<ИМЯ>_MODEL`); у LM Studio — модель не загружена |
| «не хватило контекста» | `lms load qwen3.5-4b --context-length 16384` или начни новый чат |
| «Semantic search is unavailable» | нет bge-m3 в LM Studio: поиск работает по словам, см. шаг 4 |
| модель отвечает текстом без цитат | модель плохо вызывает инструменты — смени модель или провайдера |
| `uv` не найден / `ModuleNotFoundError` | `pip install uv`, затем `uv sync`; команды — через `uv run` |

## Где что

- `src/research_assistant/` — код. Провайдеры — `providers.py`, настройки — `config.py`, агент — `agent/`, веб — `ui/`.
- `.nexus-map/INDEX.md` — карта проекта для ИИ: прочитай её, если нужно менять код.
- `docs/mcp.md` — подключение библиотеки к Claude Code, Hermes, Codex, Cursor; `.mcp.json` — конфиг для Claude Code; `skills/research-library/SKILL.md` — навык с правилами цитирования (копируется в `~/.claude/skills/` или `~/.hermes/skills/`).
- `docs/experiments.md` — эксперименты и метрики; `docs/finetune.md` — дообучение (отложено).
- `eval/` — золотые вопросы для оценки.
