# Предметные понятия

## Наполнение библиотеки
- **Тема (topic)** — пользовательская тема; статья может принадлежать нескольким темам (`paper_topics`).
- **Статья (paper / `PaperRecord`)** — запись из источника; дубли склеиваются по DOI, arXiv id, OpenAlex id или нормализованному заголовку (≥20 символов).
- **Полный текст** — `fulltext_status`: pending / ok / failed / unavailable; формат pdf или html (CyberLeninka). Без полного текста в поиск идёт аннотация из метаданных (`source = metadata`).
- **Раздел (section)** — заголовок + тип (`abstract`, `introduction`, `method`, `experiments`, `results`, `discussion`, `conclusion`, `limitations`, `appendix`, `other`, `body`). `body` — текст без заголовков; фильтр по типу раздела его не отсекает.
- **Фрагмент (passage)** — единица поиска, ≤220 слов, со страницей; `kind` = text или caption.
- **Предложение (sentence)** — единица цитирования; ID отображается как `s123`, фрагмент как `p123`.
- **Сущность (entity)** — method / dataset / metric / task; ключ = основы слов (`key`), так что словоформы совпадают; хранится, только если встречается в тексте. **Упоминание (entity_mention)** — связь сущности с фрагментом.

## Хранилище и поиск
- **Анализатор** (`nlp/text.analyze`) — токены → стоп-слова → основы Snowball по алфавиту слова (кириллица/латиница). Один и тот же для FTS5, ключей сущностей и запросов.
- **Режимы поиска** — `bm25`, `dense`, `hybrid` (RRF, k = 60); флаги `translate` (BM25 по английскому переводу) и `rerank` (listwise моделью).
- **PassageFilter** — тема, годы, типы разделов, язык, статьи, сущность.

## Ответы с цитатами
- **final_answer** — `answer` + `claims[{text, sentence_ids}]` или `not_found`; принимается, только если все ID агент видел в выдаче (`ToolContext.seen_sentences`).
- **Бюджет** — 12 шагов, после 6 поисков/чтений доступен только `final_answer`.
- **prefetch** — поиск по самому вопросу до первого шага; лучший вариант в эксперименте E3 (docs/experiments.md).

## Оценка
- **Золотой вопрос** — вопрос + пары (название статьи, дословная цитата); устойчив к переразбору.
- **Успех агента** — строгий: цитата из золотого фрагмента; мягкий: из золотой статьи.
- **pass@1 / pass^k** — доля успехов / доля вопросов, успешных во всех k прогонах; для pass@1 — интервал Вильсона.
